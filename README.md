# Gruvbox for x.com

x.comの配色をGruvbox Light/Dark Mediumに置き換えるChrome拡張です。配色は[hakhatz.dev](https://hakhatz.dev)と揃えており、OSのライト/ダーク設定に連動します。

## インストール

1. `chrome://extensions`を開き、右上の「デベロッパーモード」を有効にする。
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ。
3. x.comを開いている場合は再読み込みする。

## 仕組み

Xのスタイルは実行時に生成されるCSSクラスとインラインstyleに色が直接書かれており、クラス名もビルドごとに変わります。そのため、`src/content.js`がページ内に現れた色を検出し、Gruvboxの役割(背景、本文、補助文字、アクセントなど)を指すCSS変数に書き換えます。

- 灰色系の色: 明度が近い背景・文字の役割に割り当てる。
- 有彩色: 色相でGruvboxのred/orange/yellow/green/aqua/blue/purpleに割り当てる。
- いいね・リポスト・ブックマークのボタン: 押した状態が分かりやすいよう、ピンク・緑・青などの有彩色はXの元の色のままにする(灰色のアイコンはテーマの色)。
- 通知ページの各通知のマーク: いいねやリポストの通知を色で見分けられるよう、Xの元の色のままにする。Xの青で描かれるフォローやベルのマークはテーマの青にする。
- Xの表示モード: bodyの背景色からデフォルト/ダークブルー/ブラックを判定し、モードごとに割り当てを切り替える。
- ログアウト時の画面: 別のアプリで描かれ、配色のCSSを別オリジン(abs.twimg.com)から読み込むため、CORSで読み直してから書き換える。表示モードはhtml要素の`data-theme`で判定する。

## 制約

- 対象はx.comだけです。pro.x.comなどのサブドメインには適用しません。
- 割り当ての基準にしたXの色は、デフォルト(ライト)モードのものは2026年11月にx.comで実測した値、ダークブルー・ブラックモードのものは推定値です。Xの表示はデフォルトモードのまま使うのが最も確実です。
- WCAG 2.2 AAの4.5:1に届かないGruvboxの文字色は、一段濃い(ダークでは明るい)色に替えるか、背景と反対側の色を5〜10%混ぜて補正しています(ライトの補助文字・green・aqua、ダークの補助文字・red)。
- 画像・動画の上に重なるバッジなどもテーマ側の色に反転します。ただし動画プレイヤーの操作部分、複数画像の左右移動ボタン、投稿画面の添付画像の上の編集・削除ボタン、センシティブな内容の警告は、読めなくなるためXの元の色のままにしています。
